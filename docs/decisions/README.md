# Architecture decision records

One file per decision: `NNNN-kebab-title.md`, numbered in order, never renumbered. A superseded ADR stays in place with its status changed to "Superseded by NNNN".

Each ADR has: Status, Context, Decision, Consequences. Keep it to a page.

Any new direct dependency, Rust or npm, needs an ADR or an amendment to the allowlist in 0001.
